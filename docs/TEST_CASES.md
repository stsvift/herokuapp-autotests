## Дефекты приложения

**HOVER-01:** открыть `/hovers`, навести на пользователя, проверить имя, нажать View profile. Ожидание: доступный профиль без ошибки. Фактически `/users/1`, `/users/2`, `/users/3` показывают Not Found. Три теста падают с `expected false but found true`. Подписи и ссылки до перехода проверяются отдельно и проходят. Ошибка приложения сохранена как ошибка, без инверсии ожидания.

**TYPO-01:** `/typos` случайно возвращает `won,t` вместо `won't`. В зафиксированном полном прогоне строгая орфография прошла. `paragraphsMatchDocumentedVariants` допускает только два точных текста, а `paragraphHasCorrectSpelling` остаётся строгой проверкой в группе `known-defect`. Нет перезагрузок или повторов до успешного ответа.

Группа `known-defect` содержит четыре запуска: три перехода Hovers и одну строгую проверку Typos. Она исключается только профилем `stable`; обычный `mvn test` выполняет всё.
